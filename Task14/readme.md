ETL Process Documentation:


1- Raw dataset was collected from Kaggle and stored in the raw folder.

2- Folder structure was created for raw, processed, and output data.

3- Missing values were removed and duplicate records were eliminated.

4- Column names were standardized to lowercase with underscores.

5- Data types were validated and cleaned where required.

6- Derived features were created including customer segment and high value flag.

7- Dataset was split into separate tables: customers, orders, and products.

8- Processed files were saved as CSV and also loaded into SQLite database.

9- Record counts were validated to ensure data integrity after transformation.
